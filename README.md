# 爱特工作室第三次课作业

用 MySQL 做一个简单图书数据库，记录了作者和图书信息，通过 SQL 完成查询和修改操作

## 环境

- MySQL 版本：8.4.13
- 运行方式：Docker
- 数据库名称：`bookshop`
- 本机连接地址：`127.0.0.1`
- 本机端口：`3307`

## 从空数据库复现

- 启动 MySQL 8.4 服务 & 连接数据库
- 执行 `sql/schema.sql`，创建数据库和数据表
- 执行 `sql/seed.sql`，插入作者和书的数据
- `sql/queries.sql`，查询结果，完成修改操作

`seed.sql` 应在刚创建的空表中执行一次，重复执行会插入重复数据。执行查询文件前，请先阅读其中的更新和删除语句。

## 数据库

两张表：

- `authors`：作者编号、姓名、简介和创建时间
- `books`：图书编号、书名、作者编号、价格、库存

`authors.id`  `books.id` 两张表的主键，对应具体某位作者，具体某一本书

`books.author_id` 是外键，引用 `authors.id`，表示一本书属于哪位作者, 防止图书引用不存在的作者

价格用 `DECIMAL(8, 2)` ，适合保存需要精确到小数的金额，库存使用无符号整数，避免出现负数库存

## 数据说明

数据库包含 4 位作者和 8 本书，有库存为 0 的书

## 问题与处理

在 MySQL 输入不上中文，气死我了！！！！检查后发现容器内的语言环境没有设置，客户端连接使用了 `latin1` 字符集

设置一下 `LANG=C.UTF-8`，+  `utf8mb4` 字符集 然后再重新连接，之后中文就能正常打了
